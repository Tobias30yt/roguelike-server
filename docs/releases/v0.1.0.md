# Roguelike 0.1.0 – erste Testversion

Plugin für **Paper 26.3 build 223 / Java 25** mit Hub, privaten Runs, Unlocks, Coins, Markt, Handel, Rebirth, Plots und Jahresreset. Noch keine vollständige Produktionsfreigabe; offene Funktionen stehen in der README.

## Ubuntu installieren

Für einen **neuen** Ubuntu-Server auf ARM64 (Oracle Ampere) oder x86_64:

```bash
curl -fL --proto '=https' --proto-redir '=https' https://github.com/Tobias30yt/roguelike-server/releases/download/v0.1.0/install.sh -o install.sh
sudo bash install.sh --accept-eula --start
```

Mit `--accept-eula` bestätigst du die [Minecraft-EULA](https://aka.ms/MinecraftEULA). Lasse diesen Schalter und `--start` weg, wenn du zunächst nur installieren möchtest.

Das Skript prüft die Release-Prüfsumme und installiert Java 25, Paper, die Plugin-JAR und den systemd-Dienst `roguelike`. Bestehende Server werden nicht überschrieben. Die Firewall wird nicht verändert; TCP 25565 muss in Ubuntu und Oracle freigegeben werden. Der Dienst nutzt 2 GB Java-Heap.

Die Whitelist ist aktiv. Deinen Minecraft-Namen und Operator-Rechte richtest du nach der [Startanleitung](https://github.com/Tobias30yt/roguelike-server/blob/v0.1.0/docs/START-HIER.md) ein.

## Dateien

- `Roguelike-0.1.0.jar`: Plugin für den Paper-Ordner `plugins/`.
- `Roguelike-0.1.0.zip`: Plugin, vollständiges Maven-Projekt, Konfiguration, Skripte und Dokumentation.
- `install.sh`: Ubuntu-Installation direkt aus diesem Release.
- `SHA256SUMS.txt`: SHA-256-Prüfsummen der drei Dateien.
